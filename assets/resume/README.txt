PLACE YOUR RESUME PDF HERE
===========================
File name required: Suraj_Resume.pdf
Destination path: assets/resume/Suraj_Resume.pdf

Instructions:
1. Export your resume as a PDF file from Microsoft Word, Google Docs, Canva, or LaTeX.
2. Rename the exported PDF file to exactly: Suraj_Resume.pdf
3. Place Suraj_Resume.pdf inside this "assets/resume/" folder.
4. Once placed, both the "Download Resume" and "View Resume" buttons on the portfolio will automatically download or open your actual PDF resume.
